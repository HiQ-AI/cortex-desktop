## v0.0.30 — 蜗牛开了个技能商店 🛒

以前蜗牛的技能是出厂焊死的。会什么就会什么，不会的你也没办法。

想让它学做 PPT？不好意思，出厂没装。想让它画算法艺术？更没戏。就像买了台只能打电话的手机——你想装个 App，它说"不支持"。

**现在蜗牛有应用商店了。**

打开技能中心，下面多了一排"技能市场"。每张卡片就是一个技能——名字、描述、一键安装。装完下次对话就能用。不想要了？卸载。就这么简单。

市场里目前有 11 个技能，从 Excel 到 PDF 到算法艺术，想装什么装什么。以后还会越来越多。

**蜗牛终于可以自我进化了。虽然进化的方向是你选的。**

### 🛒 技能市场

技能中心分两层：
- **已安装** — 你正在用的技能，带开关
- **技能市场** — 可以下载的新技能，一键安装

从市场安装的技能会下载完整文件（包括脚本），不是只拿个说明书。Excel 技能真的能操作 Excel，PDF 技能真的能合并 PDF。

卸载后技能自动回到市场列表。反复装卸，随你折腾。

### ✨ 技能中心长好看了

重新设计了整个界面：
- 核心技能（LCA 搜索）有专属琥珀色标识，其他技能低调内敛
- 市场技能用虚线边框暗示"还没装"
- 点击卡片展开详情面板，渐变色头部一眼识别
- 有版本更新时会显示更新标记

### 🔄 刷新按钮

不用重启 App 了。点刷新就能拉取最新的市场技能列表。我们在云端加了新技能，你刷新一下就能看到。

蜗牛开了个商店。目前只卖技能，不卖壳。🐌

### 平台
- **macOS** — arm64（Apple Silicon）
- **Windows** — x64
- **Linux** — x64（AppImage）

The snail's skills used to be hardwired at the factory. What it knows is what it knows. No returns, no upgrades.

Want it to make PPTs? Sorry, not installed. Want algorithmic art? Even less chance. Like buying a phone that only makes calls — you ask to install an app, it says "not supported."

**The snail has an app store now.**

Open the Skills Center, and there's a new "Marketplace" section below your installed skills. Each card is a skill — name, description, one-click install. Works in the next conversation. Don't want it anymore? Uninstall. That simple.

11 skills available now, from Excel to PDF to algorithmic art. Install what you want. More coming.

**The snail can finally evolve. Though you pick the direction.**

### 🛒 Skills Marketplace

Skills Center now has two sections:
- **Installed** — skills you're using, with toggles
- **Marketplace** — downloadable skills, one-click install

Marketplace skills download complete files (including scripts), not just instructions. The Excel skill actually manipulates spreadsheets. The PDF skill actually merges PDFs.

Uninstalled skills return to the marketplace. Install, uninstall, reinstall — your call.

### ✨ Refined Design

Complete UI redesign:
- Core skill (LCA Search) gets distinctive amber accent, others stay understated
- Marketplace cards use dashed borders to signal "not yet installed"
- Click a card for the detail panel with gradient header
- Update badges when new versions are available

### 🔄 Refresh Button

No more restarting the app. Hit refresh to pull the latest marketplace. We add skills on the cloud, you see them instantly.

The snail opened a shop. Only sells skills, not shells. 🐌
