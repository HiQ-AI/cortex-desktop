## v0.0.33 — 蜗牛不再串记忆了 🧠

在项目里聊的事情，蜗牛有时候会记到全局记忆里。点了左边的会话列表回到旧对话，蜗牛就忘了自己在哪个项目里。

修了。恢复旧对话时，蜗牛会自动找回它属于哪个项目，记忆写对地方。

蜗牛不串台了。🐌

### 平台
- **macOS** — arm64 | **Windows** — x64 | **Linux** — x64

---

The snail sometimes wrote project memories to the global directory. Clicking a conversation in the sidebar lost its project context.

Fixed. Resumed conversations now recover their project binding from session metadata. Memory stays isolated per project.

The snail stays in its lane now. 🐌
