## v0.0.28 — 蜗牛终于会看文件了 📎

你有没有试过这种操作——

点 `+`，选了一份 Excel，文件名漂漂亮亮地出现在对话框里，你满怀期待地点了发送。

蜗牛回你："请问您想分析哪个文件？"

**就好像你往它嘴里塞了个三明治，它问你："你有三明治吗？"**

原因很丢人：文件确实选了，也确实显示了，但发送的时候……忘带了。就像出门把钥匙放在门口鞋柜上，人走了，钥匙没走。

现在修好了。你选的文件会被复制到工作目录里，蜗牛拿到手就开始读。Excel、CSV、PDF、Word、图片——选什么读什么，不再装瞎。

**丢文件给它，它真的看得懂了。不是假装看到。**

### 📎 文件上传终于通了

以前：选文件 → 显示文件名 → 发送 → 文件消失 → 蜗牛一脸懵

现在：选文件 → 显示文件名 → 发送 → 文件到手 → 蜗牛开始分析

支持 Excel、CSV、PDF、Word、JSON、图片。选多个也行。

### 🧠 蜗牛更专注了

给蜗牛调了几个内部参数，让它干活时更专注：不乱跑后台任务，不分心做不相关的事。你给它一个活，它就盯着这个活干完。

蜗牛终于会看文件了。虽然这个功能早就该有。🐌

### 平台
- **macOS** — arm64（Apple Silicon）
- **Windows** — x64
- **Linux** — x64（AppImage）

You know when you hand someone a document, they look at it, nod... and then ask "what document?"

That was the snail. You'd click `+`, select an Excel file, see it beautifully displayed in the chat input, hit send, and—

"Which file would you like me to analyze?"

**Like feeding it a sandwich and having it ask "do you have a sandwich?"**

The embarrassing truth: the file was selected and displayed, but when sending... it was left behind. Like putting your keys on the shoe rack by the door, walking out, and the keys stayed home.

Fixed now. Selected files get copied to the working directory, and the snail starts reading immediately. Excel, CSV, PDF, Word, images — whatever you pick, it reads.

**Drop a file, it actually sees it now. Not pretending.**

### 📎 File Upload Actually Works

Before: select file → show filename → send → file vanishes → confused snail

Now: select file → show filename → send → file received → snail analyzes

Supports Excel, CSV, PDF, Word, JSON, images. Multiple files too.

### 🧠 More Focused

Tuned a few internal parameters so the snail stays focused: no background tasks, no distractions. One job at a time, all the way through.

The snail can finally read files. Should've been able to all along. 🐌
